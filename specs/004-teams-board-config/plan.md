# Implementation Plan: Teams & Board Name Unified Configuration

**Branch**: `004-teams-board-config` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-teams-board-config/spec.md`

## Summary

Merge `TEAMS` and `JIRA_BOARD_NAME` into a single `TEAMS=COMP|"Board Name",...` format. Remove the global `BoardName` field from `Config` and replace `Teams []string` with `Teams []TeamEntry`. Update all `cmd/` callers. Extend `get-sprint-label-report` to loop over all team entries rather than querying a single board.

## Technical Context

**Language/Version**: Go 1.24.0

**Primary Dependencies**: `github.com/joho/godotenv` (env loading), `github.com/andygrunwald/go-jira` (Jira API)

**Storage**: N/A — configuration is read from environment variables at startup only

**Testing**: `go test ./...` (`make test`)

**Target Platform**: macOS / Linux CLI

**Project Type**: CLI tool (multiple binaries under `cmd/`)

**Performance Goals**: N/A — config parsing is startup-only, negligible cost

**Constraints**: Must remain backwards-compatible in the sense that a missing `JIRA_BOARD_NAME` must not cause a startup error. Old single-component `TEAMS=PROCESSING` (no pipe) must fall back gracefully using the component name as the board name.

**Scale/Scope**: 3 `cmd/` binaries updated; 1 `internal/config` package changed; `.env.example` updated.
